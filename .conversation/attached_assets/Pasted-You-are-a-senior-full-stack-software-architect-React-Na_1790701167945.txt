You are a senior full-stack software architect, React Native/Expo developer,
React Native Web developer, ASP.NET Core developer, PostgreSQL developer,
UX/UI designer, offline-first application architect, and document-generation
specialist.

I want you to design and develop a complete production-quality application
for teachers to manage pupils and perform competency-based evaluations.

The application must run on:

1. Android
2. Web browser

The application must use a shared React/TypeScript codebase as much as
technically possible.

I have provided an existing Word document named:

notation.docx

and an image showing the corresponding evaluation sheet.

The existing Word document is the reference for the generated report.

IMPORTANT:
The application must NOT be designed around editing Word documents.

The database is the source of truth.

The teacher enters structured assessment data once.

That data is then used to generate:
- evaluation grids
- statistics
- pupil history
- remediation information
- Word documents
- PDF documents
- printed reports

- React Native 0.86
